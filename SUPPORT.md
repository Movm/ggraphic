# Getting help

- **Usage questions and ideas:** open a GitHub Discussion if they are enabled, otherwise an issue with the question label.
- **Bugs:** open an issue with the bug report form and a minimal reproduction.
- **Embedding the editor in your app:** start with [`packages/editor/skills/ggraphic-embed/SKILL.md`](./packages/editor/skills/ggraphic-embed/SKILL.md).
- **Self-hosting Studio:** [docs/self-hosting.md](./docs/self-hosting.md).
- **Security issues:** never in public, see [SECURITY.md](./SECURITY.md).

ggraphic is maintained by a small team. There is no commercial support and no response-time guarantee.
