# Public API inventory

Companion to [public-api-proposal.md](public-api-proposal.md). Snapshot of 2026-11-01, not kept up to date: ggraphic `main` at `665bc6b` (Studio and the packages), PR #86 at `0a2be62` (Studio after stages A and B), the Grünerator `master` at `ba5d8d44ba`.

Every `@ggraphic/*` subpath imported anywhere, counted from the TypeScript syntax tree: static and type imports, re-exports, `import()`, `vi.mock` and CSS `@import`. A `.js`/`.ts` suffix on a specifier is dropped.

- **Columns:** number of files per consumer. The Studio column covers `apps/studio` and `apps/studio-server`; a number in parentheses comes only from PR #86. Packages lists the other `@ggraphic` packages that import the subpath. A package's imports of itself are not counted.
- **Tests:** a file counts as a test when its path matches `.vitest.`, `.test.`, `.spec.`, `__tests__/`, `/test/`, `/tests/` or `/e2e/`.
- **Names used outside tests:** the named imports from Studio, the Grünerator and the packages, outside tests. `*` stands for `export *` or a namespace import. The page-model rows have no names because the scan read names only from `main`.
- **Proposed home:** the entry point from the proposal, or `internal` with the reason.
